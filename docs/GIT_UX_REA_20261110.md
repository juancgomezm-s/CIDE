## Comportamiento que debe ofrecer CIDE

1. La vista Git enlaza ramas, historial, archivos y diferencias. La selección
   tiene un estado visible y se conserva al regresar desde un archivo.
2. Cambios actuales aparece como primera entrada del historial. Se distinguen
   archivos preparados y pendientes, con sus cantidades y acciones próximas.
3. Elegir un commit actualiza los archivos de esa revisión. Elegir un archivo
   muestra su comparación y deja visible la identidad de ambas fuentes.
4. Los archivos cambiados permanecen en una lista visible con su estado y la
   selección actual. Resumen reúne los datos del commit. El selector de una,
   dos o tres columnas conserva su preferencia. Esta lista sigue la elección
   expresa de Juan del 10 de noviembre.
5. Preparar, retirar y descartar pertenecen al archivo o bloque seleccionado.
   Crear o modificar commit pertenece a la preparación revisada. Los conflictos
   tienen su propio flujo con base, actual, entrante y resultado.
6. Las acciones de consulta mantienen el contexto. Las acciones de escritura
   conservan la vista previa, confirmación y protección de cambios de CIDE.
7. Comparar en Código abre las versiones en el área central del editor y conserva
   pestañas y Explorador. Puede elegirse HEAD, índice o un commit fijado frente
   al documento abierto, incluidos sus cambios sin guardar.
8. En Código se ofrecen comparación paralela y unificada. Las líneas eliminadas
   llevan fondo rojo y las añadidas fondo verde, con sus números y finales de
   línea. Las versiones paralelas comparten la posición vertical y huecos de
   alineación. Volver a editar conserva bytes, cursor, selección e historial.

Los puntos 1–6 guían la revisión visual de la vista Git existente. Los puntos
7–8 se implementaron para GUI y TUI en este bloque. No se da por terminado
el rediseño completo del espacio de administración Git por esta entrega.

## Entradas y presentación

En la TUI, los comandos de comparar HEAD e índice conducen a Código.
El pie de la comparación anuncia el selector de commits, el modo de diferencias,
el desplazamiento vinculado, actualizar y volver a editar. En el grafo, una
acción Comparar en Código utiliza el commit seleccionado y el archivo abierto.
El selector distingue elegir una revisión de administrar operaciones del repo.

En la GUI, Ver ofrece comparar en Código con HEAD o con el índice. El botón
Código del espacio Git abre el archivo seleccionado contra el commit observado.
Dentro de Código, Revisión (F4) permite cambiar de commit y explorar ramas y
etiquetas. V alterna vista paralela/unificada y Esc regresa a editar. Las barras
vertical y horizontal actúan sobre ambas versiones. Una ventana estrecha usa
vista unificada sin perder la preferencia paralela. La lista de archivos del
espacio Git permanece como lista; no se convierte en pestañas de archivos Git.

Las herramientas del repositorio mantienen la distribución solicitada, la
tipografía compacta configurable, el tema oscuro y los textos en español.
El rediseño se valida con rutas reales de selección, comparación y regreso.

## Límites e identidades

El documento abierto (con sus cambios sin guardar) es la fuente derecha. La
izquierda es HEAD, índice o un objeto commit completo fijado, no una expresión
Git que pueda cambiar durante la consulta. Cambiar de commit vuelve a capturar
por el controlador versionado existente. Una respuesta atrasada no revive una
comparación cuyo documento cambió. Elegir revisiones no mueve HEAD ni escribe
el índice. Abrir un archivo desde Git reutiliza el documento existente; las rutas
deben ser relativas al proyecto y válidas para Windows. Un archivo ausente en
el directorio de trabajo no se recrea mediante esta acción.

La paginación visual de hasta 128 filas se comparte en jc-app::diff_rows; conserva
todas las líneas de contexto y alinea inserciones/eliminaciones sin otro motor
de diferencias. Cada frontend conserva su pintor y entrada propios. La vista de
comparación es de solo lectura: Esc recupera la edición del documento original.
La GUI evita preparar las filas editables y el minimapa ocultos detrás de Código.
Se conservan los límites de admisión de fuentes del controlador Git existente;
esta entrega no certifica comparación ilimitada de archivos de varios GB.
